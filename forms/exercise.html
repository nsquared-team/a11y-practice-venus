Issues Found (there are 8):

  • No real labels: All fields use <span> instead of <label> — no programmatic association (WCAG 1.3.1, 3.3.2)
  • Placeholder-only hints: Placeholders are the only indication of expected input format, and they disappear on focus (WCAG 3.3.2)
  • Required fields not marked programmatically: Red asterisks are visual-only — no required attribute (WCAG 1.3.1)
  • Wrong input type for phone: type="number" adds a spinner and doesn't suit phone numbers — should be type="tel" or type="text" with inputmode="tel" (WCAG 4.1.2)
  • Email field uses type="text": Should be type="email" for proper keyboard on mobile and better validation hints (WCAG 1.3.5)
  • Radio group has no fieldset/legend: "Preferred contact method" is a <p> tag, not a <legend> — screen readers skip it in forms mode (WCAG 1.3.1)
  • Disabled submit button with no explanation: Users can't submit and don't know why. Better to allow submission and show validation errors (usability / WCAG 3.3.1)
  • No error handling at all: There's no validation feedback, no error messages, no error summary — if something is wrong, users have no way to know (WCAG 3.3.1, 3.3.3)
