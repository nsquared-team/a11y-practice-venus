Demo 8: Custom Controls WCAG 4.1.2 — Level A

Custom-built dropdowns look polished, but without the right semantics they're invisible to assistive technology and unreachable by keyboard. Try tabbing to each dropdown and using arrow keys.

This dropdown works with a mouse — click it and pick an option. But try tabbing to it: you can't. A screen reader sees a generic <div> with no role, no label, and no indication it's interactive. It's completely invisible to non-mouse users.

Fixed

A native <select> element is keyboard accessible out of the box — Tab to it, use arrow keys to browse options, Enter to select. Screen readers announce "Your role, combo box" with the current selection. No ARIA needed because the semantics are built in.
