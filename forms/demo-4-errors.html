Demo 4: Error Messages WCAG 3.3.1 — Level A

When something goes wrong, the error must be specific, in text, and connected to the right field.

Broken

Please fix the errors above.

The red borders are invisible to screen readers. "Please fix the errors above" doesn't say which fields or what's wrong. The error text isn't connected to either field.

Fixed

Enter a complete email address, like name@example.com

Phone number is required

Each error is specific, in text, and linked to its field with aria-describedby. The aria-invalid attribute tells screen readers the field has an error.
