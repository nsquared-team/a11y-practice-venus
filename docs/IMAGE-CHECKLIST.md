## Notes

- **Image Optimization:** Compress all images for web to reduce file size while maintaining quality
- **Alt Text:** Remember to add descriptive alt text when implementing images in HTML
- **File Naming:** Use lowercase with hyphens (e.g., `ishtar-terra.jpg`, `dr-elena-vasquez.jpg`)
- **Retina Support:** Consider providing @2x versions for high-DPI displays (double the dimensions)
